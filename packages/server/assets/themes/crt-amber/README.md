# CRT Amber

A warm amber fork of CRT Phosphor. It keeps the original monochrome terminal, glowing type, scanlines, aperture-grille hint, vignette, rolling refresh band, mains flicker, block cursor, and reduced-motion behavior while changing the phosphor palette from green to amber.

## Palette

The main phosphor is `#ffbe00` (600 nm Amber). Warm highlights lean toward `#ffb700` (602 nm Selective Yellow) and `#ffa900` (606 nm Web Orange). Near-black surfaces take a subtle brown-amber cast; the CRT effects and layout otherwise follow CRT Phosphor.

## Files

`theme.css`, `manifest.json`. No assets or JavaScript.

# CRT Amber theme (UI)

CRT Amber is the installed bundled theme named `CRT Amber`, with theme ID `crt-amber`. It forks CRT Phosphor’s dark monochrome terminal treatment into an amber palette centered on `#ffbe00`.

[styles.css](./styles.css) defines its visual treatment and preserves the original scanlines, grille, vignette, refresh band, flicker, blinking cursor, and reduced-motion behavior. [README.md](../../../../packages/server/assets/themes/crt-amber/README.md) records palette intent.

The bundled-package source and production mapping are owned by [bundled installation](../../../arch/themes/bundled-installation.md).
